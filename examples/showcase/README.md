# Public showcase records

This directory contains only public documentation for the recorded demonstration.
The five checked-in clips live under `web/public/showcase/media/`; their compact public
metadata, published prompts, and published starting frames are in
`web/public/showcase/manifest.json`.

The allowlist that maps private original outputs to those public copies is intentionally
ignored under `outputs/publication/`. Do not add source paths, run records, timestamps,
or private review notes to this directory. The five selected public prompts and starting
frames are intentional exceptions and are documented in the manifest.
